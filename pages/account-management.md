# 계정 관리
## 회원가입

지오코더 서비스를 이용하기 위해 회원으로 가입하세요. 회원가입 시 자동으로 7일간의 Pro 회원 혜택이 제공됩니다.
### 회원가입 절차
1. 상단 네비게이션 바에서 **"회원가입"** 버튼을 클릭합니다.
2. 필수 정보(사용자명, 이메일, 비밀번호)를 입력합니다.
3. "회원가입" 버튼을 클릭하여 가입을 완료합니다.
4. 가입 즉시 API 토큰이 발급되고, 7일간의 Pro 혜택이 적용됩니다. 발급된 토큰을 사용자 프로필에서 확인할 수 있으며 API 호출시 사용합니다.
#### Pro 혜택 안내

회원가입 시 자동으로 7일간의 Pro 회원 혜택이 부여됩니다:
- 월 건 지오코딩 및 리버스 지오코딩

7일 후에는 일반 회원으로 전환됩니다.
- 월 건 지오코딩 및 리버스 지오코딩
## 로그인 및 로그아웃
#### 로그인 방법
1. 상단 네비게이션 바에서 **"로그인"** 버튼을 클릭합니다.
2. 사용자명과 비밀번호를 입력합니다.
3. "로그인" 버튼을 클릭하여 로그인을 완료합니다.
#### 로그아웃 방법
1. 상단 네비게이션 바에서 **사용자명**을 클릭합니다.
2. 드롭다운 메뉴에서 **"로그아웃"**을 선택합니다.
#### 비로그인 사용 제한 안내

비로그인 사용자(데모 모드)는 한 번에 최대 **100건**까지만 지오코딩할 수 있으며, 지도 불러오기 기능을 사용할 수 없습니다. 더 많은 주소를 처리하려면 로그인하세요.
## 비밀번호 재설정
1. 로그인 페이지에서 **"비밀번호를 잊으셨나요?"** 링크를 클릭합니다.
2. 가입 시 사용한 이메일 주소를 입력합니다.
3. 이메일로 받은 링크를 통해 새 비밀번호를 설정합니다.
