# 프로필 관리
## 프로필 확인 및 수정

로그인 후 프로필 페이지에서 개인 정보를 확인하고 수정할 수 있습니다.
#### 프로필 접근 방법
1. 상단 네비게이션 바에서 **사용자명**을 클릭합니다.
2. 드롭다운 메뉴에서 **"내 프로필"**을 선택합니다.
#### 수정 가능한 정보
- 이름
- 이메일 주소
- 비밀번호

#### 프로필 화면에서 확인 가능한 정보
- API 사용 통계
- 일일/월간 쿼터 사용량
- Pro 회원 상태 및 만료일
- API 토큰 정보
## API 토큰 관리

API 토큰은 지오코더 API를 프로그래밍 방식으로 호출할 때 필요한 인증 수단입니다.

또한, 웹 페이지에서 지오코딩할 때에도 적용됩니다.
#### 토큰 발급 및 재발급
1. 프로필 페이지에서 **"API 토큰 관리"** 섹션으로 이동합니다.
2. 토큰이 없는 경우 **"토큰 생성"** 버튼을 클릭합니다.
3. 토큰을 재발급하려면 **"토큰 재발급"** 버튼을 클릭합니다.

토큰을 재발급하면 기존 토큰은 즉시 무효화됩니다. 신중하게 결정하세요.
#### 토큰 보안 팁
- 토큰은 암호처럼 안전하게 보관하세요.
- 공개 저장소(GitHub 등)에 토큰을 포함하지 마세요.
- 토큰 유출이 의심되면 즉시 재발급 받으세요.
## API 사용량 확인
#### 프로필 페이지에서 확인 가능한 통계
- 일일 API 호출 / 일일 쿼터
- 이번 달 API 호출 수
- 일일 쿼터 사용 현황
- 월별 쿼터 사용 현황

#### 상세 사용 내역 보기

더 자세한 사용 내역을 보려면 프로필 페이지 하단의 **"상세 사용 내역 보기"** 버튼을 클릭하세요.

상세 내역에서 확인 가능한 정보:
- 날짜/시간별 API 호출 내역
- 엔드포인트별 사용량
- 성공/실패 건수
- 처리 시간
## 계정 삭제

더 이상 서비스를 이용하지 않으려면 계정을 삭제할 수 있습니다.
#### 주의사항

계정 삭제는 되돌릴 수 없으며 모든 정보가 영구적으로 삭제됩니다.
- 개인 계정 정보가 삭제됩니다.
- API 토큰이 무효화됩니다.
- 모든 API 사용 기록이 삭제됩니다.
- 저장된 지도가 삭제됩니다.
#### 계정 삭제 방법
1. 프로필 페이지에서 페이지 하단으로 스크롤합니다.
2. **"계정 관리"** 섹션에서 **"회원 탈퇴"** 버튼을 클릭합니다.
3. 확인 대화상자에서 비밀번호를 입력하고 삭제 동의를 체크합니다.
4. **"회원 탈퇴"** 버튼을 클릭하여 계정 삭제를 완료합니다.
