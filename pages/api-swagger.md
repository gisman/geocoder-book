# API Swagger 문서 (온라인 테스트)

지오코더 API의 모든 엔드포인트를 대화형으로 테스트할 수 있는 Swagger UI 문서입니다.

## Swagger UI 접속

Swagger UI를 통해 모든 API 엔드포인트의 명세를 확인하고 직접 테스트할 수 있습니다.

**접속 URL**: https://geocode-api.gimi9.com/docs/

## 주요 기능

### 1. API 명세 확인
- 모든 엔드포인트의 HTTP 메서드
- 요청 파라미터와 타입
- 응답 스키마
- 에러 코드와 메시지

### 2. 온라인 테스트
웹 브라우저에서 직접 API를 호출하여 결과를 확인할 수 있습니다.

**테스트 방법:**
1. Swagger UI에서 테스트할 엔드포인트를 클릭
2. "Try it out" 버튼 클릭
3. 요청 파라미터 입력 (필수: token)
4. "Execute" 버튼을 클릭하여 요청 전송
5. 응답 결과 확인

### 3. curl 명령어 생성
각 엔드포인트의 curl 명령어를 자동으로 생성할 수 있습니다.

**사용 방법:**
1. Swagger UI에서 테스트 항목 아래의 curl 명령어 확인
2. 명령어를 복사하여 터미널에서 실행

## 주요 엔드포인트

### 주소 지오코딩
```
GET /geocode - 소수 주소 지오코딩
POST /geocode - 대량 주소 지오코딩 (최대 10,000건)
```

### 역 지오코딩
```
GET /reverse_geocode - 좌표를 주소로 변환
```

### 행정구역 검색
```
GET /region - 코드로 행정구역 형상 검색
GET /region_by_coordinate - 좌표로 행정구역 형상 검색
```

### 행정동 이력
```
GET /hd_history - 행정동 변경 이력 조회
```

### 토큰 통계
```
GET /token/stats - API 사용량 통계 조회
```

## 테스트 팁

### 1. 토큰 설정
모든 요청에 유효한 토큰이 필요합니다. 
- [계정 설정](./../../account-management.md)에서 토큰을 확인하세요
- 각 요청 시 token 파라미터에 토큰을 입력하세요

### 2. 샘플 데이터
Swagger UI에서 제공하는 샘플 값을 사용하여 테스트할 수 있습니다.

**예시:**
- 주소: "서울특별시 송파구 송파대로8길 10"
- 좌표: 경도 127.1146829, 위도 37.5138498

### 3. 대량 요청 테스트
POST /geocode 엔드포인트로 대량의 주소를 한 번에 처리할 수 있습니다.

## 오류 해결

### 403 Forbidden (인증 오류)
- 토큰이 올바른지 확인하세요
- 토큰이 만료되었을 수 있습니다. 계정 설정에서 다시 확인하세요
- 토큰 사용량이 초과되었을 수 있습니다. [토큰 통계](./token-statistics.md)를 확인하세요

### 400 Bad Request (파라미터 오류)
- 요청 파라미터가 올바른지 확인하세요
- 필수 파라미터가 모두 입력되었는지 확인하세요
- 파라미터의 형식과 타입을 확인하세요

### 500 Internal Server Error
- 일시적인 서버 오류입니다. 잠시 후 다시 시도하세요
- 반복되면 고객 지원팀에 문의하세요
