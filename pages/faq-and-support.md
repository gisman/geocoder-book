# 자주 묻는 질문 및 지원

## 자주 묻는 질문

### API 토큰을 재발급받으면 어떻게 되나요?

기존 토큰은 즉시 무효화됩니다. 이전 토큰을 사용하던 애플리케이션과 서비스에서 새 토큰으로 업데이트하세요. 토큰 유출이 의심될 때 재발급하는 것이 좋습니다.

### 일일 할당량을 초과하면 어떻게 되나요?

해당 날짜의 API 요청은 더 이상 처리되지 않고 할당량 초과 오류가 반환됩니다. 할당량은 한국 시간 기준 매일 자정에 초기화됩니다. Pro 회원은 더 많은 일일 할당량을 사용할 수 있습니다.

### 주소 지오코딩이 실패하는 일반적인 이유는 무엇인가요?

주소가 불완전하거나 모호한 경우, 오타나 띄어쓰기 오류, 데이터베이스에 없는 최신 건물·도로명, 비표준 주소 형식 또는 존재하지 않는 주소 때문에 실패할 수 있습니다. 상세한 주소와 공식 도로명주소 형식을 사용하세요.

### 광역시도나 시군구가 생략된 주소도 지오코딩할 수 있나요?

파일 지오코딩 화면에서 **주소 힌트**를 입력하면 누락된 행정구역 정보를 보완할 수 있습니다. 예를 들어 `서울 종로구`를 힌트로 지정하면 `내수동 72번지`를 `서울 종로구 내수동 72번지`로 처리합니다.

### Pro 회원은 어떻게 신청하나요?

월간 또는 연간 구독을 결제하면 됩니다. Pro 상태로의 업그레이드는 24시간 이내에 적용됩니다.

### Pro 체험 기간이 끝나면 비용이 청구되나요?

체험 기간이 끝나면 자동으로 일반 회원으로 전환되며, 일반 회원은 별도 요금 없이 이용할 수 있습니다.

### 지원되는 좌표계는 무엇인가요?

파일 지오코딩에서 다음 좌표계를 선택할 수 있습니다.

- EPSG:4326 (WGS84, GPS 경위도)
- EPSG:5174 (한국 중부원점)
- EPSG:5178 (UTM-K/Bessel)
- EPSG:5179 (UTM-K/GRS80)
- EPSG:5181 (카카오맵 좌표계)
- EPSG:5186 (한국 2000 중부원점)
- KATECH (국가교통DB 좌표계)

### 무료로 API 서버를 사용할 수 있나요?

일반 회원은 하루 최대 10만 건까지 사용할 수 있습니다. 더 많은 사용량이 필요하면 Pro 버전을 이용하세요. 구매 문의: [gisman@gmail.com](mailto:gisman@gmail.com)

### 데이터는 얼마나 자주 업데이트되나요?

지오코딩 데이터는 매일 업데이트되며, 역지오코딩과 행정동 이력 데이터는 월 1회 업데이트됩니다.

### 어떤 데이터를 사용하나요?

지오코딩은 주소정보 누리집의 공공데이터를 사용합니다. 역지오코딩은 브이월드의 연속지적도와 건물도형 공공데이터를 사용합니다.

### 처리 속도는 얼마나 빠른가요?

지오코딩은 초당 3천 건, 시간당 1천만 건 이상을 처리하며 역지오코딩도 비슷한 속도를 제공합니다. Enterprise 서버는 여러 노드를 구성해 처리 속도를 높일 수 있습니다.

### Enterprise 서버의 권장 사양은 무엇인가요?

- 최저 사양: AWS EC2 t2.micro (1 vCPU, 1 GiB 메모리)
- 권장 사양: 8코어 이상 CPU, 16 GiB 메모리
- 저장 공간: 약 70 GB. 무중단 업데이트에는 140 GB 권장
- 운영체제: Ubuntu 22.04 이상 또는 RHEL 10 이상 권장

사양에 맞지 않는 환경은 사전에 문의하세요.

### Enterprise 서버를 Docker로 설치할 수 있나요?

Docker 환경을 완벽하게 지원합니다.
