# 지원 및 문의

문제가 발생하거나 질문이 있으신가요? 다양한 방법으로 지원을 받을 수 있습니다.

## 📞 연락 방법

### GitHub Discussions (권장)

**[GitHub Discussions](https://github.com/gisman/geocoder-kr/discussions)에서 질문하세요.**

GitHub Discussions은 다음과 같은 이점이 있습니다:
- 커뮤니티 전체가 볼 수 있는 공개 Q&A
- 답변이 다른 사용자들에게도 도움이 됩니다
- 검색 가능한 기록 유지
- 개발팀의 빠른 응답

**사용 방법:**
1. [GitHub 저장소](https://github.com/gisman/geocoder-kr)로 이동
2. "Discussions" 탭 클릭
3. "New discussion" 클릭
4. 질문하신 내용 작성

### 카톡 오픈채팅 (빠른 답변)

**[카톡 오픈채팅](https://open.kakao.com/o/gNplQr7f)에서 직접 문의하세요.**

빠르게 답을 얻으려면 카톡 오픈채팅을 추천합니다:
- 실시간 채팅으로 빠른 응답
- 개발팀과 직접 소통
- 급할 때 사용하기 좋습니다

**주의:** 카톡 오픈채팅은 임시 대화이므로 중요한 내용은 GitHub에서 기록하시기 바랍니다.

## 🐛 버그 리포트

버그를 발견하셨나요? GitHub Issues에 보고해주세요.

**버그 리포트 작성 팁:**

다음 정보를 포함해주면 빠른 해결에 도움이 됩니다:

```markdown
## 버그 설명
[여기에 버그에 대한 명확한 설명을 작성해주세요]

## 재현 단계
1. [첫 번째 단계]
2. [두 번째 단계]
3. [세 번째 단계]
...

## 예상 동작
[예상되는 동작을 설명해주세요]

## 실제 동작
[실제로 발생한 동작을 설명해주세요]

## 환경
- OS: [예: Ubuntu 22.04]
- Python 버전: [예: 3.11]
- 지오코더 버전: [예: 1.0.0]
- 추가 정보: [필요시 추가 정보]

## 스크린샷 (선택사항)
[해당하는 경우 스크린샷 첨부]
```
