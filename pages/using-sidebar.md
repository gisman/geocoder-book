# 사이드바 활용하기
## 결과

지오코딩 처리 결과를 목록 형태로 확인할 수 있습니다.
#### 시각화 주의사항
- 표와 시각화는 최대 1만건 까지만 표시됩니다.
- 전체 결과를 확인하려면 파일을 다운로드하세요.
#### 주요 기능
- **결과 필터링**: 성공/실패 체크박스로 원하는 결과만 표시
- **항목 클릭**: 목록의 항목을 클릭하면 지도에서 해당 위치로 이동
- **상태 표시**: 성공(초록색), 실패(빨간색) 등 시각적 구분
- **상세 정보**: 각 항목의 지오코딩 결과 정보 표시
#### 결과 해석
- **성공**: 정확한 좌표가 부여된 경우
- **실패**: 지오코딩에 실패한 경우 (Pro 회원은 실패 원인 확인 가능)
- **대표 좌표**: 완전하지 않은 주소의 행정구역 대표 좌표
#### 결과 활용 팁
- 실패한 항목을 클릭하여 원인을 파악하고 주소를 수정할 수 있습니다.
- 필터를 활용하여 성공한 결과만 보고 지도에서 분포를 확인하세요.
- 목록에서 스크롤하여 많은 결과를 빠르게 탐색할 수 있습니다.
## 표

파일의 지오코딩 결과를 표 형태로 상세하게 확인할 수 있습니다.
#### 표 기능
- **전체 데이터 보기**: 원본 데이터와 지오코딩 결과를 모든 컬럼으로 표시
- **정렬**: 컬럼 헤더를 클릭하여 데이터 정렬
- **복사**: 테이블 복사 버튼을 클릭하여 클립보드에 복사
#### 표에서 확인 가능한 정보
- 원본 파일의 모든 컬럼
- 지오코딩 성공 여부
- 변환된 X, Y 좌표
- 행정구역 코드 및 명칭
- Pro 회원: 행정동 이력 및 실패 원인
#### 표 활용 팁
- 좌표 컬럼을 정렬하여 지역 순서로 확인할 수 있습니다.
- 표에서 행을 클릭하면 지도에서 해당 위치로 이동합니다.
## 차트

지오코딩 결과를 다양한 차트로 시각화 할 수 있습니다.
#### 제공되는 차트
- **성공률 차트**: 전체 데이터 대비 성공/실패 비율을 파이 차트로 표시
- **지오코딩 결과 분포**: 결과 유형별(정확한 주소, 대표 좌표 등) 분포를 파이 차트로 표시
#### 차트 활용
- 데이터 품질 평가: 성공률을 통해 주소 데이터의 품질 확인
- 지역별 분포 파악: 어느 지역에 데이터가 집중되어 있는지 확인
- 결과 유형 분석: 정확한 주소와 대표 좌표의 비율 확인
#### 차트 해석 팁
- 성공률이 낮다면 주소 데이터를 검토하고 수정을 고려하세요.
- 차트를 이미지로 저장하여 보고서에 활용할 수 있습니다.
## 시각화

지오코딩 결과를 다양한 방식으로 지도에 시각화할 수 있습니다.
#### 시각화 유형
- **포인트 맵**: 각 위치를 개별 마커로 표시 (기본값)
- **클러스터 맵**: 인접한 포인트들을 그룹화하여 표시
- **히트맵**: 데이터 밀도를 색상으로 표시
- **행정구역 맵**: 행정구역별 데이터 개수를 색상으로 구분
#### 시각화 활용 사례
- **포인트 맵**: 정확한 위치 확인이 필요한 경우
- **클러스터 맵**: 대량 데이터의 전체적인 분포 파악
- **히트맵**: 밀집도가 높은 지역 식별
- **행정구역 맵**: 행정구역별 통계 비교
#### 범례
- 자동으로 데이터 분포에 따라 최대 6개의 색상 구간으로 나누어 표시됩니다.
- 각 구간의 최솟값과 최댓값이 표시되어 데이터 분포를 쉽게 이해할 수 있습니다.
- 각 구간의 데이터 개수가 표시되어 해당 구간의 데이터 밀도를 파악할 수 있습니다.
#### 범례 해석 가이드
- **히트맵 범례**: 색상이 진할수록 해당 지역의 데이터 밀도가 높음
- **행정구역 맵 범례**: 숫자가 클수록, 색상이 진할수록 해당 행정구역의 데이터 개수가 많거나 또는 색상 기준으로 선택한 컬럼의 합계가 큼
- **클러스터 맵**: 원의 크기와 숫자로 포함된 데이터 개수 표시
- **색상 구분**: 자동으로 데이터 분포에 따라 최적의 색상 구간을 설정
#### 색상 기준
- 기본 값은 "개수" 입니다. 행정구역 맵을 제외한 맵은 각 포인트마다 1개로 계산됩니다. 행정구역 맵은 각 행정구역에 포함된 데이터 개수를 기준으로 색상이 적용됩니다.
- 원본 데이터의 컬럼과 지오코딩 결과 컬럼을 선택하여 시각화를 최적화할 수 있습니다.
- 숫자 컬럼은 합산하여 계산됩니다.
- 숫자가 아닌 컬럼을 선택하면 값에 따라 서로 다른 색상으로 구분되어 시각화됩니다.
#### 색상 척도
- 시각화는 최솟값부터 최댓값까지 6개 구간으로 나누어 각 구간에 색상 적용.
- 분위 수: 데이터 순위를 기준으로 6개 구간으로 나누어 색상을 적용합니다. 이는 상대 평가 방식과 유사합니다.
- 일정 간격: 전체 데이터 범위를 일정한 6개 구간으로 나누어 색상을 적용합니다. 이는 절대 평가 방식과 유사합니다.
#### 색상 팔레트
- 히트맵과 행정구역 맵에 적용됩니다.
#### 불투명도
- 0.0: 완전히 투명한 상태로 배경 지도가 보입니다.
- 1.0: 불투명한 상태로 배경 지도를 완전히 가립니다.
- 기본 값은 0.8로 설정되어 있습니다.
#### 시각화 선택 가이드
- **데이터 개수가 적은 경우 (100건 미만)**: 포인트 맵 사용
- **데이터 개수가 많은 경우 (1000건 이상)**: 클러스터 맵이나 히트맵 사용
- **밀집 지역 분석이 목적인 경우**: 히트맵 사용 (범례로 밀도 수준 확인)
- **지역별 비교가 목적인 경우**: 행정구역 맵 사용 (색상 척도로 수치 비교)
- **색상이 겹쳐 보이기 어려운 경우**: 불투명도를 조정하거나 다른 시각화 방식 선택
## 지도 불러오기

이전에 처리한 지오코딩 결과를 다시 불러와서 확인할 수 있습니다.
#### 지도 불러오기 기능
- **사용 내역 확인**: 최근 지오코딩 처리 내역을 시간순으로 표시
- **빠른 접근**: 카드를 클릭하여 즉시 해당 결과를 지도에 표시
- **처리 정보 확인**: 성공/실패 건수, 처리 시간 등 요약 정보 제공
- **검색 기능**: 특정 파일이나 작업을 빠르게 찾기
#### 보관 기간
- **일반 회원**: 3일간 보관
- **Pro 회원**: 구독 기간 동안 보관
- **비로그인 사용자**: 사용 내역 저장되지 않음
#### 활용 팁
- 정기적으로 필요한 지오코딩 결과를 로컬에 다운로드하여 백업하세요.
- 협업 시 동료와 지오코딩 결과를 공유할 때 유용합니다. url을 공유하세요.
