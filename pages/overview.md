# 소개 및 계정 관리

## 지오코더 소개

기미나인 지오코더는 대한민국 주소 전용 지오코딩 솔루션입니다. 도로명 주소와 지번 주소를 지리적 좌표(위도·경도)로 변환하고, 좌표를 다시 주소로 변환하는 역지오코딩을 지원합니다.

주요 기능:

- 주소 지오코딩 및 역지오코딩
- 파일 및 공공데이터 지오코딩
- 지도 시각화 및 공유
- 초고속 처리와 간편한 API
- 쉬운 설치 및 데이터 업데이트
- Enterprise 온프레미스 호스팅

## 회원가입 및 로그인

1. 상단 탐색 메뉴에서 **회원가입**을 선택합니다.
2. 사용자명, 이메일, 비밀번호를 입력하고 가입을 완료합니다.
3. 가입 즉시 API 토큰이 발급되며, 7일간 Pro 혜택이 적용됩니다. 토큰은 프로필에서 확인할 수 있습니다.

신규 가입 시 7일 동안 월 1억 건의 지오코딩 및 역지오코딩을 사용할 수 있습니다. 체험 기간이 끝나면 일반 회원으로 전환되며 월 사용량은 300만 건입니다.

로그인하려면 상단의 **로그인**을 선택해 사용자명과 비밀번호를 입력합니다. 로그아웃은 사용자명 메뉴에서 **로그아웃**을 선택합니다. 비밀번호를 잊은 경우 로그인 페이지에서 **비밀번호를 잊으셨나요?**를 선택한 뒤 가입 이메일로 받은 링크를 사용해 재설정합니다.

비로그인 사용자는 한 번에 최대 100건까지 지오코딩할 수 있으며, 지도 불러오기 기능은 사용할 수 없습니다.

## 프로필 관리

로그인 후 상단의 사용자명 메뉴에서 **내 프로필**을 선택합니다. 프로필에서 이름, 이메일 주소, 비밀번호를 수정할 수 있으며 다음 정보를 확인할 수 있습니다.

- API 사용 통계와 일일·월간 쿼터
- Pro 회원 상태 및 만료일
- API 토큰 정보
- 날짜·시간 및 엔드포인트별 상세 사용 내역, 성공·실패 건수와 처리 시간

### API 토큰 관리

프로필의 **API 토큰 관리**에서 토큰을 생성하거나 재발급할 수 있습니다. 토큰을 재발급하면 기존 토큰은 즉시 무효화됩니다.

토큰은 비밀번호처럼 안전하게 보관하세요. 공개 저장소에 올리지 말고, 유출이 의심되면 즉시 재발급하세요.

### 계정 삭제

계정 삭제는 되돌릴 수 없습니다. 계정 정보, API 토큰, 사용 기록 및 저장된 지도가 영구 삭제됩니다.

프로필 하단의 **계정 관리**에서 **회원 탈퇴**를 선택하고, 확인 대화상자에서 비밀번호를 입력한 뒤 삭제에 동의하면 탈퇴가 완료됩니다.

지오코딩에 성공한 경우에만 사용량에서 차감됩니다. 신규 가입자는 7일간 Pro 기능을 사용할 수 있으며, 체험 기간과 구독 기간은 프로필에서 확인할 수 있습니다. 유료 구독은 결제일로부터 1년간 제공됩니다. 체험 기간이 끝나면 자동으로 일반 회원으로 전환되고 일일·월간 한도도 일반 회원 수준으로 조정됩니다. 계속 Pro 혜택을 이용하려면 [관리자에게 문의](https://geocode.gimi9.com/contact)하세요.
