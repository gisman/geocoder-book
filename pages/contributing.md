# 오픈소스 기여

지오코더는 오픈소스 프로젝트이며, 모든 종류의 기여를 환영합니다!

## 기여 방법

### 저장소 포크 및 풀 리퀘스트

[GitHub 저장소](https://github.com/gisman/geocoder-kr)를 포크하고 풀 리퀘스트를 보내주세요.

**기여 프로세스:**
1. 저장소를 포크합니다
2. 기능 브랜치를 생성합니다 (`git checkout -b feature/amazing-feature`)
3. 변경사항을 커밋합니다 (`git commit -m 'Add amazing feature'`)
4. 브랜치를 푸시합니다 (`git push origin feature/amazing-feature`)
5. 풀 리퀘스트를 생성합니다

## 기여 유형

모든 종류의 기여를 환영합니다:

### 🐛 버그 리포트
- 발견한 버그를 GitHub Issues에 보고해주세요
- 재현 방법, 예상 동작, 실제 동작을 명확하게 작성해주세요
- 가능하면 환경 정보(OS, Python 버전 등)를 포함해주세요

### ✨ 기능 제안
- 새로운 기능에 대한 아이디어를 공유해주세요
- 사용 사례와 함께 제안해주세요
- 디자인 및 구현 방식에 대해 논의합니다

### 📚 문서 개선
- 오타 및 문법 오류 수정
- 문서의 명확성 개선
- 예제 코드 추가
- 번역 개선

### 🔍 지오코딩 안 되는 주소 리포팅
지오코딩이 작동하지 않는 주소를 발견하셨나요?

**다음 정보와 함께 보고해주세요:**
- 지오코딩 안 되는 주소
- 예상 결과 (좌표나 올바른 주소)
- 실제 결과 (에러 메시지)
- 사용한 API 버전

이 정보는 데이터베이스를 개선하고 지오코딩 정확도를 높이는 데 큰 도움이 됩니다.

## 오픈소스 라이선스 사용

다음의 경우 오픈소스 버전을 자유롭게 사용할 수 있습니다:

### ✅ 무료 사용 가능

| 사용 케이스 | 설명 |
|-----------|------|
| **개인적 사용** | 개인이 비영리 목적으로 소프트웨어를 사용하는 경우 |
| **교육 목적** | 학교, 대학 등 교육 기관에서 학습 및 연구 목적으로 사용하는 경우 |
| **비영리 단체** | 자선 단체, NGO 등이 그들의 미션을 수행하기 위해 사용하는 경우 |
| **오픈소스 프로젝트** | 다른 비상업적 오픈소스 프로젝트에서 해당 솔루션을 활용하는 경우 |
| **정부 기관** | 공공 서비스 제공을 위해 정부 기관에서 사용하는 경우 |
| **학술 연구** | 대학이나 연구소에서 순수 학술 목적으로 사용하는 경우 |

### 💼 상업적 사용

상업적 용도로 사용하려면 Pro 버전을 구독하거나 엔터프라이즈 라이선스를 취득해야 합니다.

**라이선스 구입 문의:** [gisman@gmail.com](mailto:gisman@gmail.com)

## 행동 강령

이 프로젝트에 참여하시는 모든 분들은 다음을 준수해주세요:

- 존중하고 포용적인 태도 유지
- 다양한 관점을 존중
- 건설적인 피드백 제공
- 공격적이거나 모욕적인 언어 금지
- 타인의 개인정보 존중

## 개발 환경 설정

지오코더에 기여하고 싶으신가요? 로컬 개발 환경을 설정하세요:

```bash
# 저장소 클론
git clone https://github.com/gisman/geocoder-kr.git
cd geocoder-kr

# 의존성 설치
pip install -r requirements-dev.txt

# 테스트 실행
pytest

# 린트 체크
flake8 src/
black src/
```

## 풀 리퀘스트 가이드라인

풀 리퀘스트를 보내실 때 다음을 확인해주세요:

- ✅ 테스트를 추가/업데이트했습니다
- ✅ 문서를 업데이트했습니다
- ✅ 코드 스타일을 맞췄습니다 (black, flake8)
- ✅ 커밋 메시지가 명확합니다
- ✅ 이슈와의 연관성을 설명했습니다 (해당하는 경우)
