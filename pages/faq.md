# 자주 묻는 질문 (FAQ)

## API 및 토큰 관리

### API 토큰을 재발급받으면 어떻게 되나요?

API 토큰을 재발급받으면 기존 토큰은 즉시 무효화됩니다. 따라서 기존 토큰을 사용하던 모든 애플리케이션이나 서비스에서 새 토큰으로 업데이트해야 합니다. 토큰 재발급은 토큰이 유출됐을 때 보안을 위해 실시하는 것이 좋습니다.

### 일일 할당량을 초과하면 어떻게 되나요?

일일 할당량을 초과하면 해당 날짜에는 더 이상 API 요청이 처리되지 않습니다. "할당량 초과" 오류 메시지가 반환됩니다. 할당량은 매일 자정(한국 시간 기준)에 초기화됩니다. Pro 회원으로 업그레이드하면 더 많은 일일 할당량을 이용할 수 있습니다.

### 무료로 API 서버를 사용할 수 있나요?

하루에 100,000건까지 사용할 수 있습니다. 그 이상 필요하면 Pro 버전(유료)을 사용하세요. 

**구입 문의:** [gisman@gmail.com](mailto:gisman@gmail.com)

## 주소 지오코딩

### 주소 지오코딩이 실패하는 일반적인 이유는 무엇인가요?

주소 지오코딩이 실패하는 주요 원인:

- **주소가 불완전하거나 모호함** - 예: "서울시 강남구"처럼 상세 주소 없음
- **오타나 띄어쓰기 오류**
- **데이터베이스에 없는 최신 건물이나 도로명**
- **비표준 주소 형식 사용**
- **존재하지 않는 주소 입력**

**정확도를 높이는 방법:**
- 상세한 주소를 입력하세요
- 공식 도로명주소 형식을 사용하세요
- 오타와 띄어쓰기를 정확히 입력하세요

### 광역시도, 시군구가 생략된 주소를 지오코딩할 수 있나요?

가능합니다! 파일 지오코딩 화면에서 **[주소 힌트]**를 입력하세요. 누락된 광역시도, 시군구 정보를 자동으로 보완하여 지오코딩을 수행합니다. 

**예시:**
- 주소 힌트: "서울 종로구"
- 입력 주소: "내수동 72번지"
- 결과: "서울 종로구 내수동 72번지"

## Pro 회원

### Pro 회원은 어떻게 신청하나요?

Pro 회원 신청은 월간 또는 연간 구독을 결제하면 됩니다. 24시간 이내에 Pro 상태로 업그레이드됩니다.

### Pro 체험 기간이 끝나면 비용이 청구되나요?

아니요. Pro 체험 기간이 종료되면 자동으로 무료 회원으로 전환되며, 무료 회원은 별도의 요금 없이 이용할 수 있습니다.

## 좌표계

### 지원되는 좌표계는 무엇인가요?

지오코더는 다음의 좌표계를 지원합니다:

| 좌표계 | 설명 |
|--------|------|
| EPSG:4326 | WGS84, GPS 경위도 (기본값) |
| EPSG:5174 | 한국 중부원점 |
| EPSG:5178 | UTM-K/Bessel |
| EPSG:5179 | UTM-K/GRS80 |
| EPSG:5181 | 카카오맵 좌표계 |
| EPSG:5186 | 한국 2000 중부원점 |
| KATECH | 국가교통DB 좌표계 |

파일 지오코딩 시 원하는 좌표계를 선택할 수 있습니다.

## 데이터

### 데이터 업데이트는 얼마나 자주 하나요?

- **주소 데이터**: 매일 업데이트합니다
- **리버스 지오코딩 및 행정동 이력**: 월 1회 업데이트합니다

### 어떤 데이터를 사용하나요?

**주소 지오코딩:**
지오코딩은 [주소정보 누리집](https://www.juso.go.kr/)의 여러 공공데이터를 사용합니다.

**리버스 지오코딩:**
리버스 지오코딩은 [브이월드](https://gimi9.com/organization/vworld/)의 연속지적도와 건물도형 공공데이터를 사용합니다.

## 성능

### 처리 속도는 얼마나 빠른가요?

- **지오코딩**: 초당 3,000건, 시간당 1,000만 건 이상 처리 가능
- **리버스 지오코딩**: 지오코딩과 유사한 속도

**엔터프라이즈 서버의 경우:**
여러 개의 노드를 구성하여 처리 속도를 더 높일 수 있습니다.

## 엔터프라이즈 서버

### 엔터프라이즈 서버의 권장 사양은?

**최저 사양:**
- CPU: 1 vCPU (AWS EC2 t2.micro 수준)
- 메모리: 1GiB

**권장 사양:**
- CPU: 8core 이상
- 메모리: 16GiB 이상

**저장 공간:**
- 기본: 약 70GB
- 무중단 업데이트 고려 시: 140GB (두 배)

**운영체제:**
- Ubuntu 22.04 이상
- RHEL 10 이상

> 위 사양에 맞지 않는 환경이라면 사전에 문의해 주세요.

### 엔터프라이즈 서버를 Docker로 설치할 수 있나요?

가능합니다. Docker 환경을 완벽하게 지원합니다.
